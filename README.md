### 💫 About Me
I build practical, scalable software—ranging from full-stack web platforms to automated data workflows and local AI tools. Currently focused on **NOVA Ops**, an end-to-end Event Management Solution designed for seamless registrations, smart admin controls, and real-world scalability.

- 🧩 **NOVA Ops:** Event registration platform featuring an admin dashboard, QR-based attendance tracking, automated ID card generation, and data exports.
- 🤖 **AI & Automation:** Experimenting with AI/ML, local LLMs, and browser automation to build smarter workflows.
- 📊 **Data & Dashboards:** Building interactive analytics dashboards, reporting tools, and data-handling utilities.
